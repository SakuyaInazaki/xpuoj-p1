# 另一台机器需要准备/重新下载的东西

## 结论：分两种情况

### 1) 只做远程提交（不本地编译 GPU 代码）

不需要重新下载任何大型包。只要：

- Python3 + `requests`
- 凭据：`.secrets/xpuoj.json`（建议安全复制）
- 提交脚本：`scripts/xpuoj_api.py`、`scripts/submit.py`，或本文件夹 `tools/`
- 要提交的题目代码

远程评测机会提供题目运行环境；本机当前其实也没有用于 P1 的 torch/triton 环境。

### 2) 需要本地编译/复现（CUDA / tilelang 相关工作）

> 重要：做 P1 时没有使用这些目录。P1 全程是本地编辑代码 -> `py_compile` ->
> API 远程提交 -> 远程评测 -> 解析结果。以下目录来自本机此前其他题目/实验，
> 另一台机器如果只做 P1 或只做远程提交，不需要它们。

这些不是重新下载能恢复的（submission 历史详情可通过 API 按 id 查，但本地日志/候选文件无法从平台找回），应整体复制或打包传输。

## 最小跨机提交包建议

如果只是让另一个 agent 远程提交，不需要 2.9G 的本地编译目录，只需：

```text
xpuoj-p1/scripts/xpuoj_api.py
xpuoj-p1/scripts/submit.py
xpuoj-p1/scripts/best_score.py
xpuoj-p1/.secrets/xpuoj.json
要提交的代码文件
```

再加一个 `requests` 即可开始工作。
